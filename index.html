Use one or choose more

Standalone school tools under one TrackEDU brand.

House Points, Facilities and Class Board solve different problems. Each product can work independently, so schools can choose only what they need and add another TrackEDU tool later.

01

Start with one product

Need a house point system? Use House Points. Need room booking? Use Facilities. Need classroom tools? Use Class Board. There is no requirement to use the others.

02

Add another when it helps

A school can adopt another TrackEDU product later without changing the purpose or workflow of the tool it already uses.

03

Keep data relevant

Products only need the information relevant to their job. Facility Booking, for example, does not need student records.

TrackEDU is growing as a suite, without turning every school task into one oversized system. Simple products first. Connections only where they genuinely make the school day easier.
