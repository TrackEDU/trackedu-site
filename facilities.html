FAQ

Common questions

Is this only for classrooms?

No. Schools can add classrooms, halls, labs, libraries, sports areas, auditoriums, meeting rooms and any other shared spaces.

Can some rooms require approval?

Yes. High-demand spaces can require administrator approval, while everyday spaces can be available for faster booking.

Can teachers use it on mobile?

Yes. The facility portal is web-based and supports progressive web app installation, so it can work like an app on supported devices.

Does it support recurring bookings?

Yes. Staff can make recurring bookings where the school allows them, making regular room use easier to manage.

Can it be used without the full TrackEDU ecosystem?

Yes. TrackEDU Facilities can be bought as a standalone Facility Management System, or used as part of the full TrackEDU ecosystem.
